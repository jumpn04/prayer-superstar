# Prayer Superstar

Phone-friendly prayer practice page for kids.

- Traditional prayer lines and home bhajans stay in the SAY IT cards.
- Kid meanings, games, and try-this notes were written for this page.
- Not a scan of a publisher booklet. Not for sale.

Open `index.html` or `prayer-superstar.html` in a phone browser.

If GitHub Pages is on: https://jumpn04.github.io/prayer-superstar/
